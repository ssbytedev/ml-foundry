The one equation to remember

Average over where you land: reward now plus value later

Q(s,a) = ΣT(s,a,s′)·[R(s,a,s′) + γ·V(s′)]

T: chance

Weight each outcome by how likely it is.

R: now

Reward collected on this transition.

γ: discount

Future reward counts a bit less.

V(s′): later

Best you can do from where you land.

Then V(s) = max over a of Q(s,a). The max sits outside the sum because you choose before the dice roll.

Why value iteration converges

Each sweep shrinks the error by a factor of γ

‖BU − BV‖ ≤ γ · ‖U − V‖

  • Rewards cancel when you subtract.
  • max can't widen a gap (|max f − max g| ≤ max |f − g|).
  • An average of gaps is at most the biggest gap.
  • So the gap to V_opt is at most γⁱ times the starting gap, which goes to 0.

Two fixed points would have to be distance 0 apart, so the answer is unique. Problem 2 relies on exactly this.

Error after i sweeps (γ = 0.7)

i = 0, 1, 2, … 7: bars are 0.7ⁱ

Problem 2a

A discount is a coin flip that might end the game

s

old s′ ∈ S

o (game over)

prob λ·T, reward R/λ

prob 1 − λ, reward 0

New MDP with γ′ = 1:

T′(s,a,s′) = λ·T(s,a,s′)
T′(s,a,o) = 1 − λ
R′(s,a,s′) = R(s,a,s′)/λ
R′(s,a,o) = 0

Plug in, and λ·(R/λ) = R. Since V′(o) = 0, the new recurrence is the old one, symbol for symbol. Uniqueness of the fixed point then gives V′ = V.

PDF §10 · probabilities check: λ·1 + (1 − λ) = 1

Alternative that also works: keep R on normal moves and pay the expected reward on the jump to o. Verified numerically on random MDPs to 1e-14.

Reinforcement learning

No rulebook? Two ways to learn from experience

Model-based (3b)

Count what happens, then plan.

T̂ = count(s,a→s′) / count(s,a)
R̂ = avg reward on s,a→s′

Then run value iteration on (T̂, R̂) every 10⁵ steps.

Model-free (4a)

Skip the model; learn Q directly.

target = r + γ·max Q(s′,·)
Q ← Q + η·(target − Q)

Every single step nudges one Q-value.

Both learn from the same experience: tuples (s, a, r, s′) returned by env.step().

PDF §6 · counts are the maximum-likelihood estimate (proof in the PDF)

Model-based weakness: a model learned from few samples can be confidently wrong. Test 3b-2 shows this: by luck a1 looked better everywhere, so planning picked a1 everywhere.

Mountain Car

The engine is weaker than gravity, so back up first

① swing left to gain height

② ride the momentum right

State: (position x, velocity v)

Actions: 0 left · 1 coast · 2 right

v += (a−1)·0.001 − cos(3x)·0.0025
v = clip(v, ±max_speed)
x += v

Goal: x ≥ 0.5. Every step costs a little.

Discretized: 20 edges per coordinate, about 400 bins.

Why value iteration needs the discrete version: you cannot loop over or store a value for infinitely many real-valued states.

Problem 4c · function approximation

Learn weights, not a table

Predict

Q(s,a) = φ(s) · W[:, a]

One weight column per action.

Compare

error = Q − target

Target treated as a fixed number.

Step

W[:,a] −= η·error·φ(s)

Gradient of ½·error².

Tabular Q-learning is the special case where φ(s) is one-hot: exactly one feature is 1.

First update in the tests: φ(0,0) is all ones, η = 0.005, target −1, so column 1 becomes −0.005 everywhere.

Problems 4d and 4e · simulated stand-ins

Tabular is steady here; function approximation is fragile

Tabular: eval ≈ −220, about 100% success

Function approx.: learned, then collapsed

Why tabular wins (4d): 36 smooth waves can't draw Q's sharp cliffs; every update shifts Q everywhere; bootstrapped off-policy updates with function approximation have no convergence guarantee; and 400 bins are easy to fill.

When FA wins (4e): it generalizes to unvisited states, uses far less memory than 20ᵈ cells in high dimensions, and needs no discretization.
